Java + Bedrock Crossplay

Tutorial membuat pemain Minecraft Java Edition dan Bedrock Edition dapat bermain pada server yang sama menggunakan GeyserMC dan Floodgate.

Yang dibutuhkan

  • Server Minecraft Java.
  • GeyserMC.
  • Floodgate.
  • ViaVersion disarankan untuk kompatibilitas versi.
  • Allocation/port UDP untuk Bedrock.

1. Install plugin

Install GeyserMC, Floodgate dan ViaVersion pada server Java kamu.

2. Buat allocation Bedrock

Buka menu Network/Allocations pada panel dan buat port tambahan yang akan digunakan pemain Bedrock.

Penting: Bedrock menggunakan koneksi UDP. Pastikan allocation yang digunakan tersedia dan sesuai dengan konfigurasi Geyser.

3. Konfigurasi Geyser

Atur listener Bedrock menggunakan port allocation yang telah dibuat.

Untuk koneksi backend, gunakan alamat dan port server Java kamu.

Jika menggunakan Floodgate, authentication Geyser diarahkan ke Floodgate.

4. Restart server

Simpan konfigurasi kemudian restart server.

5. Cara pemain join

Pemain Java menggunakan alamat dan port Java. Pemain Bedrock menggunakan alamat server dengan port Bedrock yang telah dibuat.

Setup GeyserMC

GeyserMC berfungsi sebagai bridge antara Minecraft Bedrock dan Minecraft Java.

1. Install Geyser

Upload atau install plugin Geyser yang sesuai dengan software server kamu.

2. Install Floodgate

Floodgate diperlukan apabila kamu ingin pemain Bedrock dapat terhubung menggunakan sistem autentikasi Floodgate.

3. Buat port Bedrock

Buat allocation tambahan untuk listener Bedrock dan gunakan port tersebut pada konfigurasi Geyser.

Catatan: Jangan menggunakan port Java sebagai port Bedrock apabila konfigurasi kamu menggunakan allocation terpisah.

Setup Floodgate

Floodgate bekerja bersama Geyser untuk membantu autentikasi pemain Bedrock pada server Java.

1. Install Floodgate

Pasang Floodgate pada server yang sudah menggunakan Geyser.

2. Restart

Restart server agar folder dan konfigurasi Floodgate dibuat.

3. Periksa Console

Pastikan tidak terdapat error Floodgate atau Geyser ketika server selesai startup.

Optimasi Server Minecraft

1. Gunakan software yang sesuai

Untuk server plugin-based, Paper atau Purpur dapat digunakan sesuai kebutuhan.

2. Perhatikan view distance

View distance yang terlalu tinggi dapat meningkatkan beban server.

3. Periksa plugin

Plugin yang terlalu berat atau melakukan operasi berlebihan dapat memengaruhi performa.

4. Gunakan Spark

Spark dapat digunakan untuk melakukan profiling ketika server mengalami masalah performa.

1. Buka Console

Cari nama plugin yang muncul pada error.

3. Tes tanpa plugin
