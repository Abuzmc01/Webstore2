Install Plugin Minecraft

Plugin menambahkan fitur baru ke server Minecraft Java, misalnya proteksi, ekonomi, atau crossplay Bedrock.

1. Pastikan software mendukung plugin

Plugin hanya jalan di software berbasis Bukkit seperti Paper, Purpur, atau Spigot. Server Vanilla, Fabric, dan Forge tidak bisa memakai plugin (Fabric/Forge memakai mod).

2. Download plugin dari sumber resmi

Ambil plugin dari SpigotMC, Hangar (hangar.papermc.io), Modrinth, atau GitHub resmi pembuatnya. Hindari plugin "premium gratis" dari situs tidak jelas karena sering berisi malware.

Cek versi: pastikan plugin mendukung versi Minecraft server kamu. Lihat bagian Supported versions di halaman plugin.

3. Upload ke folder plugins

Buka File Manager, masuk ke folder:

/plugins

Upload file berekstensi .jar. Kalau plugin dibungkus .zip, ekstrak dulu dan upload jar-nya saja. Jangan taruh jar di dalam subfolder.

4. Pasang dependency

Banyak plugin butuh plugin lain, misalnya Vault, ProtocolLib, atau PlaceholderAPI. Kalau dependency tidak ada, console akan menampilkan Unknown/missing dependency plugins.

5. Restart server

Restart lewat tombol Restart di panel. Jangan memakai /reload atau PlugMan karena sering membuat plugin error atau memory leak.

Setelah server menyala, ketik plugins di Console. Plugin berwarna hijau berarti berhasil dimuat, merah berarti gagal. Lihat Plugin Error kalau ada yang merah.

Java + Bedrock Crossplay

Ringkasan cara membuat pemain Java dan Bedrock (HP, Windows, konsol) bermain di server yang sama dengan GeyserMC dan Floodgate.

Cara kerjanya

  • Geyser menerjemahkan koneksi Bedrock ke Java, jadi pemain Bedrock bisa masuk server Java.
  • Floodgate membuat pemain Bedrock bisa masuk tanpa akun Java.
  • ViaVersion dibutuhkan kalau versi server lebih lama dari versi Java terbaru, karena Geyser selalu mengikuti versi Java terbaru.

Yang dibutuhkan

  • Server Paper/Purpur (atau Velocity untuk network).
  • Geyser versi terbaru dan Floodgate.
  • Satu allocation tambahan untuk port Bedrock.
  • Pemain Bedrock versi 26.40 ke atas.

Perubahan penting Oktober 2026

Sejak Bedrock 26.60 (rilis 27 Oktober 2026), client Bedrock tidak lagi memakai koneksi RakNet lama dan beralih ke NetherNet. Akibatnya:

  • Geyser wajib diupdate ke 2.12.1 build 1273 atau lebih baru.
  • Port Bedrock sekarang butuh TCP dan UDP, bukan UDP saja.
  • Port Bedrock tidak boleh sama dengan port Java (clone-remote-port: false).

Kalau sebelum Oktober crossplay sudah jalan tapi sekarang pemain Bedrock tidak bisa masuk, ikuti panduan Setup GeyserMC versi terbaru.

Langkah lengkap

  1. Setup GeyserMC (server tunggal Paper/Purpur).
  2. Setup Floodgate.
  3. Pasang ViaVersion kalau versi server di bawah versi Java terbaru.
  4. Untuk network: Geyser di Velocity.

Setup GeyserMC (Versi Terbaru)

Panduan pasang Geyser di server Paper/Purpur MineIDHost, sudah menyesuaikan perubahan NetherNet di Bedrock 26.60.

1. Download plugin

Download dari geysermc.org/download:

  • Geyser-Spigot.jar (dipakai juga untuk Paper dan Purpur)
  • floodgate-spigot.jar
  • ViaVersion.jar dari Hangar/SpigotMC, kalau server bukan versi Java terbaru

Upload semuanya ke folder /plugins, lalu restart server sekali supaya config dibuat.

2. Buat allocation untuk Bedrock

Buka tab Network di panel, klik Create Allocation. Catat nomor port baru tersebut.

Allocation di panel MineIDHost otomatis membuka TCP dan UDP, jadi satu port sudah cukup untuk NetherNet.

Tidak bisa tambah allocation? hubungi support MineIDHost lewat Discord atau ticket untuk meminta port tambahan.

3. Edit config Geyser

Buka plugins/Geyser-Spigot/config.yml dan sesuaikan bagian ini:

bedrock: address: 0.0.0.0 port: 19132 # ganti dengan port allocation tambahan clone-remote-port: false transport: nethernet remote: address: auto port: 25565 # biarkan, otomatis mengikuti server auth-type: floodgate
  • port: isi dengan port allocation dari langkah 2.
  • address: harus 0.0.0.0. Jangan 127.0.0.1 karena NetherNet akan gagal.
  • clone-remote-port: harus false, karena port Java sudah dipakai TCP oleh server.
  • transport: nethernet untuk Bedrock 26.60 ke atas. Isi both hanya kalau masih ada pemain versi lama, dan itu butuh port UDP kedua di webrtc-port.
  • auth-type: floodgate supaya pemain Bedrock tidak perlu akun Java.
Catatan: urutan dan komentar di config bisa sedikit berbeda antar build. Yang penting nilai kunci di atas sama.

4. Restart dan cek console

Restart server. Kalau berhasil, console menampilkan baris seperti:

Built-in signaling started on http://0.0.0.0:PORT

Cek versi Geyser dengan command:

geyser version

Pastikan build-nya 1273 atau lebih baru.

5. Cara pemain Bedrock join

Di Minecraft Bedrock: Play → Servers → Add Server. Isi alamat server (misalnya play.namaserver.com) dan port Bedrock, bukan port Java.

Saat pertama kali join, pemain bisa melihat pertanyaan trust on first use. Itu normal karena koneksi signaling memakai HTTP. Pilih lanjut.

Pemain konsol: Xbox, PlayStation, dan Switch tidak bisa menambah server dengan mengetik alamat. Mereka perlu cara khusus, misalnya aplikasi BedrockTogether atau trik DNS.

Masalah umum

GejalaSolusi
"Unable to connect to world" setelah update BedrockUpdate Geyser ke build terbaru, pastikan transport: nethernet dan port memakai allocation sendiri.
Console: Built-in signaling cannot use port ... because the Java server already uses itSet clone-remote-port: false dan isi port dengan allocation tambahan.
Console: RakNet and NetherNet each need their own UDP portKamu memakai transport: both. Ganti ke nethernet, atau isi webrtc-port dengan port lain.
Console: NetherNet support is NOT enabledConfig lama masih transport: raknet. Ganti ke nethernet.

Kalau masih gagal, jalankan geyser dump dan kirim link yang muncul ke support MineIDHost.

Setup Floodgate

Floodgate membuat pemain Bedrock bisa masuk server Java tanpa memiliki akun Minecraft Java.

1. Install Floodgate

Upload floodgate-spigot.jar (server biasa) atau floodgate-velocity.jar (proxy) ke folder plugins, lalu restart.

2. Hubungkan dengan Geyser

Di config Geyser, set:

auth-type: floodgate

Kalau Geyser dan Floodgate ada di server yang sama, Geyser otomatis membaca kunci Floodgate.

3. Nama pemain Bedrock

Pemain Bedrock mendapat awalan titik, misalnya .Steve123, supaya tidak bentrok dengan nama Java. Awalan bisa diubah di plugins/floodgate/config.yml bagian username-prefix. Jangan dikosongkan karena nama Bedrock bisa sama dengan akun Java orang lain.

4. Network dengan proxy

File key.pem harus sama di proxy dan semua backend. Lihat Geyser di Velocity.

5. Periksa console

Setelah restart, pastikan tidak ada error Floodgate. Error key atau decrypt biasanya berarti key.pem berbeda antar server.

Command berguna: fwhitelist add NamaBedrock untuk whitelist pemain Bedrock, linkaccount untuk menghubungkan akun Java dan Bedrock milik orang yang sama.

Multi Version (ViaVersion)

ViaVersion membuat pemain dengan versi Minecraft berbeda bisa masuk ke server yang sama.

Plugin yang dibutuhkan

PluginFungsi
ViaVersionClient lebih baru bisa masuk server lama (misalnya client terbaru masuk server 1.20.1).
ViaBackwardsClient lebih lama bisa masuk server baru. Butuh ViaVersion.
ViaRewindClient 1.7 dan 1.8 bisa masuk. Butuh ViaVersion dan ViaBackwards.

1. Install

Download dari Hangar (hangar.papermc.io) atau SpigotMC, upload ke /plugins, lalu restart.

Di network Velocity, cukup pasang di proxy atau di backend, jangan dua-duanya.

2. Wajib untuk crossplay Bedrock

Geyser selalu mengikuti versi Java terbaru. Kalau server kamu versi lama, pemain Bedrock akan kena "Outdated server" tanpa ViaVersion.

3. Selalu update

Setiap Minecraft rilis versi baru, update ViaVersion juga. Versi lama tidak mengenali client terbaru.

Catatan: blok dan item baru tidak muncul di server lama. Pemain versi baru akan melihat versi pengganti yang paling mirip.

Upload World Minecraft

Pindahkan world dari singleplayer atau hosting lain ke server MineIDHost lewat File Manager atau SFTP.

1. Stop server dan backup

Matikan server, lalu buat backup di menu Backups supaya world lama bisa dikembalikan kalau ada masalah.

2. Siapkan folder world

Folder world yang benar berisi file level.dat serta folder region. World singleplayer ada di .minecraft/saves/NamaWorld.

Kompres folder world menjadi .zip supaya upload lebih cepat.

3. Upload dan ekstrak

Upload file zip ke folder utama server, klik titik tiga di samping file, lalu pilih Unarchive. Untuk world besar (di atas 1 GB), lebih aman upload lewat SFTP.

4. Sesuaikan nama world

Buka server.properties dan isi level-name dengan nama folder world:

level-name=NamaWorld

Paper dan Purpur menyimpan dimensi secara terpisah, jadi strukturnya seperti ini:

NamaWorld/ (Overworld) NamaWorld_nether/ (Nether, isi folder DIM-1) NamaWorld_the_end/ (End, isi folder DIM1)

World dari singleplayer menyimpan Nether dan End di dalam satu folder (DIM-1 dan DIM1). Paper akan memindahkannya otomatis saat pertama kali start.

5. Start server

Nyalakan server dan cek Console. Kalau world dari versi Minecraft yang lebih lama, server akan mengupgrade chunk secara bertahap.

Penting: world tidak bisa diturunkan versinya. World dari 1.21 tidak bisa dibuka di server 1.20.

World Bedrock (.mcworld) tidak bisa langsung dipakai di server Java. Konversi dulu dengan tool seperti Chunker (chunker.app).

Ganti Versi Server

Cara mengganti versi Minecraft atau software server (misalnya Paper ke Purpur) tanpa kehilangan data.

1. Backup terlebih dahulu

Buat backup di menu Backups. Upgrade versi mengubah file world dan tidak bisa dibatalkan tanpa backup.

2. Cek kompatibilitas

  • Pastikan plugin utama sudah mendukung versi baru.
  • Upgrade boleh, downgrade world tidak disarankan karena chunk bisa rusak.
  • Pastikan versi Java sesuai. Lihat Versi Java Server.

3. Ubah versi di Startup

Buka tab Startup, ubah variabel versi Minecraft (misalnya MINECRAFT_VERSION) ke versi yang diinginkan. Biarkan build number latest kecuali kamu butuh build tertentu.

Di bagian Docker Image, pilih Java yang sesuai dengan versi baru.

4. Reinstall server

Buka tab Settings, klik Reinstall Server. Proses ini mengunduh jar server versi baru. World, plugin, dan konfigurasi tidak dihapus, tetapi tetap pastikan backup sudah ada.

5. Start dan cek console

Nyalakan server, tunggu sampai muncul Done, lalu cek apakah ada plugin yang error.

Menjadi Operator

Operator (OP) memberikan akses ke semua command admin di server.

Memberi OP lewat Console

Buka Console di panel dan ketik:

op NamaPlayer

Ganti NamaPlayer dengan username Minecraft. Pemain Bedrock lewat Geyser memakai awalan titik, misalnya op .NamaBedrock.

Mencabut OP

deop NamaPlayer

Lebih aman pakai plugin permission

OP memberi akses ke semua command. Untuk staff, lebih aman memakai LuckPerms dan memberi permission sesuai kebutuhan saja.

Keamanan: jangan memberi OP ke akun yang tidak kamu kenal. Di server offline-mode (cracked), pasang plugin login seperti MDHSecurity supaya akun OP tidak bisa dipakai orang lain.

Whitelist Server

Whitelist membatasi server hanya bisa dimasuki pemain yang terdaftar.

Aktifkan whitelist

whitelist on

Tambah dan hapus pemain

whitelist add NamaPlayer whitelist remove NamaPlayer whitelist list

Keluarkan pemain yang tidak terdaftar

Supaya pemain yang sedang online tapi tidak ada di whitelist langsung dikeluarkan, aktifkan di server.properties:

enforce-whitelist=true

Pemain Bedrock

Untuk pemain Bedrock lewat Geyser + Floodgate, gunakan command Floodgate:

fwhitelist add NamaBedrock
Catatan: di server offline-mode, whitelist berdasarkan nama mudah dipalsukan. Kombinasikan dengan plugin login.

Optimasi Server Minecraft

Langkah praktis supaya server tetap lancar walaupun pemain dan world bertambah.

1. Pakai software yang tepat

Gunakan Paper atau Purpur untuk server plugin. Keduanya jauh lebih ringan daripada Spigot atau Vanilla.

2. Atur view & simulation distance

Di server.properties:

view-distance=8 simulation-distance=6

Simulation distance menentukan seberapa jauh mob dan redstone tetap aktif, jadi pengaruhnya paling besar ke CPU.

3. Pre-generate world

Pembuatan chunk baru adalah penyebab lag terbesar saat pemain menjelajah. Generate chunk lebih dulu dengan MDHOptimized (/mdho pregen start world 5000) atau Chunky, lalu pasang world border.

4. Batasi entity dan redstone

Farm besar, item di tanah, dan mesin redstone bisa membuat TPS turun. MDHOptimized bisa membatasi entity per chunk, membekukan redstone yang berlebihan, dan memberi tahu lokasi masalahnya.

5. Profiling dengan Spark

Kalau tetap lag, cari penyebabnya dengan plugin Spark:

spark profiler start (tunggu 3-5 menit saat lag terjadi) spark profiler stop

Spark memberi link laporan yang menunjukkan plugin atau bagian server yang paling berat.

6. Jangan pakai plugin "RAM cleaner"

Plugin yang mengklaim membersihkan RAM atau memanggil garbage collector biasanya justru membuat lag spike. Java sudah mengatur memori sendiri.

Allocation / Port

Allocation adalah port jaringan yang dimiliki server kamu di panel.

Port utama dan port tambahan

Port utama (Primary) dipakai server Minecraft Java. Port tambahan bisa dibuat di tab Network → Create Allocation.

Setiap allocation di panel MineIDHost membuka TCP dan UDP sekaligus.

Kapan butuh port tambahan?

  • Geyser untuk pemain Bedrock (wajib sejak Bedrock 26.60).
  • Voice chat (Simple Voice Chat, PlasmoVoice) yang memakai UDP.
  • Dynmap, BlueMap, atau web map lain.
  • Query atau RCON.

Cara memakai port tambahan

Masukkan nomor port tersebut di config plugin yang membutuhkannya, lalu restart server. Jangan memakai port Java untuk plugin lain.

Port habis? jumlah allocation tergantung paket. Hubungi support kalau butuh tambahan.

SFTP

SFTP dipakai untuk upload dan download file besar (world, modpack, backup) lebih cepat dan stabil daripada lewat browser.

1. Lihat detail SFTP

Buka tab Settings di panel. Di bagian SFTP Details ada alamat server (beserta port) dan username.

2. Pakai aplikasi SFTP

  • Windows: WinSCP atau FileZilla.
  • macOS/Linux: FileZilla atau Cyberduck.
  • Android: aplikasi file manager yang mendukung SFTP.

3. Login

  • Protocol: SFTP (bukan FTP).
  • Host dan port: sesuai SFTP Details.
  • Username: sesuai SFTP Details (formatnya username.idserver).
  • Password: password akun panel kamu.
Gagal login? pastikan memilih SFTP, bukan FTP, dan port mengikuti SFTP Details (bukan port Minecraft).

Server Tidak Start

Langkah memeriksa server yang mati sendiri, stuck saat startup, atau langsung crash.

1. Baca console paling bawah

Scroll Console ke baris error terakhir sebelum server berhenti. Biasanya ada kata ERROR, Exception, atau nama plugin.

2. Cocokkan dengan masalah umum

Pesan / gejalaSolusi
UnsupportedClassVersionErrorVersi Java salah. Lihat Versi Java Server.
Failed to bind to portPort di config tidak sesuai allocation. Kembalikan server-port di server.properties ke port utama.
You need to agree to the EULABuka eula.txt, ubah menjadi eula=true.

Error menyebut nama pluginPlugin tidak cocok dengan versi server. Lihat Plugin Error.

Ganti nama folder plugins menjadi plugins_off, lalu start. Kalau server menyala, masalahnya ada di salah satu plugin. Kembalikan plugin satu per satu untuk menemukan penyebabnya.

4. Masih gagal?

Klik tombol share/upload log di console atau salin 50 baris terakhir, lalu kirim ke support MineIDHost.

Server Lag

Cara mengetahui apakah lag berasal dari server, dan menemukan penyebabnya.

1. Cek TPS dan MSPT

Ketik tps (Paper) atau spark tps. TPS normal adalah 20. MSPT di atas 50 ms berarti server tidak sanggup memproses tick dan pemain akan merasakan lag.

TPS 20 tapi tetap lag? masalahnya kemungkinan ping/internet pemain, bukan server.

2. Cari chunk bermasalah

Dengan MDHOptimized:

mdho status mdho scan 10 mdho alerts

Perintah ini menunjukkan chunk dengan entity terbanyak dan lokasi farm atau redstone yang berlebihan.

3. Profiling

Jalankan spark profiler start saat lag terjadi, tunggu beberapa menit, lalu spark profiler stop. Buka link yang diberikan untuk melihat plugin atau proses paling berat.

4. Penyebab umum

  • Pemain menjelajah chunk baru: pre-generate world dan pasang world border.
  • Item dan mob menumpuk: pakai clear lag terjadwal dan limit entity per chunk.
  • Mesin redstone/hopper besar: batasi dengan redstone limiter.
  • View/simulation distance terlalu tinggi.
  • Plugin yang menjalankan task terlalu sering.

Lihat juga Optimasi Server.

Setup Velocity Proxy

Velocity menghubungkan beberapa server (misalnya Lobby, Survival, Skyblock) menjadi satu network dengan satu alamat.

Yang dibutuhkan

  • Satu server Velocity sebagai proxy (port ini yang dipakai pemain).
  • Satu atau lebih server Paper/Purpur sebagai backend.
  • Alamat dan port setiap backend (lihat tab Network di panel).

1. Daftarkan backend di velocity.toml

Start Velocity sekali, lalu edit velocity.toml:

online-mode = true player-info-forwarding-mode = "modern" [servers] lobby = "IP_BACKEND_1:PORT" survival = "IP_BACKEND_2:PORT" try = ["lobby"]

Kalau server kamu menerima pemain non-premium dan memakai plugin login di proxy (misalnya MDHSecurity), set online-mode = false di proxy.

2. Salin forwarding secret

Velocity membuat file forwarding.secret berisi kode acak. Kode ini harus sama di semua backend.

3. Atur setiap backend Paper

Di server.properties backend:

online-mode=false

Di config/paper-global.yml:

proxies: velocity: enabled: true online-mode: true secret: 'ISI_DARI_forwarding.secret'

Di spigot.yml, pastikan bungeecord: false.

4. Restart semua server

Restart backend dulu, lalu proxy. Pemain join lewat alamat dan port Velocity, bukan port backend. Pindah server dengan /server survival.

Keamanan: dengan modern forwarding + secret, backend menolak koneksi yang tidak lewat proxy. Jangan bagikan isi forwarding.secret.

Crossplay Bedrock di network

Pasang Geyser di proxy, bukan di backend. Lihat Geyser di Velocity.

Geyser di Velocity / BungeeCord

Untuk network dengan proxy, Geyser cukup dipasang di proxy. Pemain Bedrock masuk lewat proxy lalu bisa pindah server seperti pemain Java.

1. Pasang di proxy

Upload ke folder plugins server Velocity:

  • Geyser-Velocity.jar (atau Geyser-BungeeCord.jar)
  • floodgate-velocity.jar (atau floodgate-bungee.jar)

Jangan pasang Geyser di backend Paper kalau sudah ada di proxy.

2. Buat allocation dan edit config

Tambahkan allocation di server proxy, lalu edit plugins/Geyser-Velocity/config.yml dengan nilai yang sama seperti Setup GeyserMC langkah 3 (address: 0.0.0.0, clone-remote-port: false, transport: nethernet, auth-type: floodgate).

3. Floodgate di backend (opsional, disarankan)

Supaya plugin di backend tahu siapa pemain Bedrock (misalnya untuk menu form Bedrock atau skin), pasang juga floodgate-spigot.jar di setiap backend.

  1. Salin file plugins/floodgate/key.pem dari proxy ke folder plugins/floodgate/ di setiap backend. File ini harus sama persis.
  2. Di plugins/floodgate/config.yml milik proxy, set send-floodgate-data: true.
  3. Restart backend, lalu proxy.

4. Versi backend

Geyser mengikuti versi Java terbaru. Kalau backend memakai versi lama (misalnya 1.20.1), pasang ViaVersion di proxy atau di setiap backend supaya pemain Bedrock tidak kena "Outdated server".

5. Pemain join

Pemain Bedrock memakai alamat server dan port Bedrock milik proxy. Pemain Java tetap memakai port Velocity.

HAProxy: kalau proxy berada di belakang HAProxy/TCPShield, daftarkan IP proxy tersebut di haproxy-protocol-whitelisted-ips pada config Geyser supaya IP asli pemain terbaca.

Item Custom & Disconnect di Bedrock

Solusi pemain Bedrock yang disconnect, item tidak muncul, atau model custom rusak di server yang memakai ItemsAdder, MMOItems, atau ModelEngine.

Kenapa terjadi?

Resource pack Java tidak bisa langsung dibaca Bedrock. Item dan model custom harus dikonversi menjadi resource pack Bedrock plus mapping untuk Geyser. Kalau mapping tidak cocok dengan resource pack, pemain Bedrock bisa disconnect saat memegang atau memakai item tersebut.

1. Update semuanya bersamaan

Update Geyser, Floodgate, dan extension/plugin pendukung (misalnya GeyserModelEngine) ke versi terbaru secara bersamaan. Versi yang tidak sinkron adalah penyebab paling umum.

2. Bersihkan resource pack lama

Buka folder plugins/Geyser-Spigot/packs/ (atau Geyser-Velocity/packs/). Hapus resource pack Bedrock versi lama, lalu ganti dengan hasil konversi terbaru. Mapping di folder custom_mappings harus berasal dari konversi yang sama.

3. Tes untuk mencari penyebab

  1. Pindahkan resource pack dari folder packs untuk sementara, lalu restart.
  2. Kalau pemain Bedrock tidak lagi disconnect, masalahnya di resource pack atau mapping.
  3. Kalau masih disconnect, lihat console tepat saat pemain keluar. Nama plugin di error biasanya menunjukkan penyebabnya.

4. Model ModelEngine

Model ModelEngine (boss, mob custom) butuh plugin seperti GeyserModelEngine agar tampil di Bedrock. Setelah menambah atau mengubah model, generate ulang resource pack Bedrock-nya dan restart server.

Tips: minta pemain Bedrock menghapus cache resource pack di pengaturan Minecraft (Storage → Cached Data) setelah resource pack diganti.

MDHSecurity

Plugin keamanan buatan MineIDHost: login & auto-login premium, anti-bot, anti-grief, log blok + rollback, dan anticheat dasar.

File dan versi

FilePasang diVersi
MDHSecurity-Velocity.jarProxy Velocity3.4+
MDHSecurity-BungeeCord.jarBungeeCord / WaterfallBuild terbaru
MDHSecurity-Paper.jarBackend Paper1.20.1 – terbaru
MDHSecurity-Purpur.jarBackend Purpur1.20.1 – terbaru

Butuh Java 17+ dan database MySQL/MariaDB. Semua server memakai database yang sama. Folia tidak didukung.

Pasang di network (dengan proxy)

  1. Buat database (misalnya minecraft) dan user MySQL. Di panel, database bisa dibuat di tab Databases.
  2. Proxy: taruh jar proxy di plugins/, start sekali, isi bagian database di config, lalu restart.
  3. Di proxy, set online-mode = false. Plugin yang menentukan pemain mana yang dicek ke Mojang.
  4. Setiap backend: taruh jar Paper/Purpur, start sekali, isi database dan server-name (beda tiap server). Biarkan auth.proxy-mode: true. Restart.
  5. Kunci backend supaya hanya bisa dimasuki lewat proxy. Velocity: player-info-forwarding-mode = "modern" + secret di paper-global.yml (lihat Setup Velocity). BungeeCord: ip_forward: true, bungeecord: true di spigot.yml, dan firewall port backend.
Penting: tanpa langkah 5, orang bisa masuk langsung ke backend dan melewati pengecekan premium.

Pasang tanpa proxy

Pakai jar Paper/Purpur saja dan set auth.proxy-mode: false.

  • online-mode=true: semua pemain premium, otomatis login.
  • online-mode=false: semua pemain Java memakai /register dan /login. Auto-login premium hanya tersedia lewat proxy.

Cara kerja login

  • Java premium: langsung masuk tanpa password. Client crack yang memakai nama premium ditolak.
  • Java non-premium: dibekukan (tidak bisa jalan, chat, command, buka chest) sampai /register atau /login.
  • Bedrock (Geyser + Floodgate): otomatis login.
  • Masuk lagi dari IP yang sama dalam remember-ip-minutes tidak perlu login. Pindah server di network juga tidak.
  • Password disimpan PBKDF2-SHA256. Hash AuthMe ($SHA$) bisa dibaca, jadi data AuthMe lama bisa dipindahkan ke tabel mdhsec_accounts.
  • Salah password max-attempts kali: kick dan IP diblokir selama block-minutes.
  • Anti-bot di proxy: batas koneksi per IP, filter nama, dan mode serangan otomatis.

Anti-grief & anticheat

  • Pemain baru: TNT, lava, flint & steel, end crystal baru bisa dipakai setelah main beberapa menit (default 120).
  • Proteksi spawn: blok, container, item frame, armor stand, ledakan, dan api di radius spawn.
  • Hewan peliharaan: hanya bisa dilukai pemiliknya.
  • Log: hancur/taruh blok, ember, ledakan, api, dan isi container.
  • Anticheat dasar: fly, speed, reach, killaura, autoclicker, fastbreak. Default hanya notifikasi + setback, tanpa kick otomatis (command-vl: 0). Kalau sudah memakai Grim/Vulcan, matikan anticheat.enabled.

MDHOptimized

Plugin optimasi buatan MineIDHost: pre-generate chunk pintar, clear lag terjadwal, limit redstone & entity, dan notifikasi lokasi masalah.

Persyaratan

  • Paper atau Purpur 1.20.1 sampai terbaru (Folia tidak didukung).
  • Java 17 atau lebih baru.

Instalasi

  1. Taruh MDHOptimized.jar di folder plugins/.
  2. Restart server (jangan /reload atau PlugMan).
  3. Edit plugins/MDHOptimized/config.yml sesuai kebutuhan.
  4. Jalankan /mdho reload.
Sudah pakai ClearLag? matikan fitur hapus item di ClearLag, atau set clear.enabled: false di MDHOptimized. Jangan jalankan dua-duanya.

Perintah

PerintahFungsi
/mdhoBantuan
/mdho statusTPS, pemain, chunk, entity, redstone yang dibekukan, waktu clear berikutnya, status pregen
/mdho scan [n]Daftar chunk dengan entity terbanyak (default 10, maks 50)
/mdho alerts30 peringatan terakhir
/mdho tp <nomor>Teleport ke lokasi peringatan (/mdho tp 1 = terbaru)
/mdho clear [items|mobs|all] [world]Clear langsung tanpa hitung mundur
/mdho pregen start <world> <radius|border> [x z]Mulai pre-generate. Radius dalam blok
/mdho pregen pause|resume|cancel|statusKontrol pregen
/mdho reloadMuat ulang config dan timer

Alias: /mdhoptimized, /mdhopt. Permission: mdhoptimized.admin (semua perintah) dan mdhoptimized.alert (menerima notifikasi), keduanya default OP.

Pre-generate chunk

/mdho pregen start world 5000 /mdho pregen start world 3000 1000 -2000 /mdho pregen start world_nether border
  • Chunk dibuat melingkar dari tengah ke luar.
  • Chunk yang sudah ada dilewati, jadi area yang sudah dijelajahi pemain tidak berubah.
  • Otomatis pause saat TPS di bawah pregen.min-tps atau pemain online terlalu banyak.
  • Progres disimpan di pregen.yml, jadi tetap lanjut setelah restart.

Clear lag

Setiap clear.interval-seconds (default 900 detik) plugin menghapus item di tanah, XP orb, panah lama, dan mob hostile. Mob passive hanya dihapus kalau passive-mobs: true.

Tidak pernah dihapus: pemain, NPC (Citizens dan sejenisnya), mob bernama, hewan jinak, mob yang dituntun atau ditunggangi, mob dari plugin (MythicMobs, ModelEngine), dan boss (Wither, Ender Dragon, Warden, Elder Guardian).

Redstone & entity limiter

  • Redstone: menghitung sinyal redstone, piston, dan hopper per chunk. Mode NOTIFY hanya memberi peringatan, THROTTLE membekukan mesin di chunk itu selama throttle-seconds.
  • Mob: spawn natural, spawner, breeding, dan sejenisnya dibatasi per chunk. Spawn dari plugin dan command tidak dibatasi, jadi boss MythicMobs tetap aman.
  • Item: default hanya notifikasi.
Tips: jalankan redstone limiter dengan NOTIFY selama sehari, cek /mdho alerts, baru ganti ke THROTTLE dengan batas yang sesuai server kamu.

FAQ

Farm pemain berhenti bekerja? Kemungkinan kena redstone limiter mode THROTTLE. Cek /mdho alerts, lalu naikkan batasnya atau ganti ke NOTIFY.

Pregen sangat lambat? Pregen pause saat TPS rendah atau banyak pemain online. Jalankan malam hari, atau naikkan chunks-per-tick dan max-in-flight kalau CPU masih longgar.

MDHAntiMalware

Plugin antivirus buatan MineIDHost yang mendeteksi plugin lain berisi malware, menonaktifkannya otomatis, dan memberi tahu admin.

Fitur

  • Memindai plugin lain yang terpasang di server untuk mendeteksi kode berbahaya.
  • Plugin yang terdeteksi berbahaya otomatis dinonaktifkan tanpa perlu mematikan server.
  • Notifikasi muncul di console dan di dalam game untuk admin.
  • Satu file jar untuk Paper, Purpur, BungeeCord, dan Velocity.

Instalasi

  1. Upload jar MDHAntiMalware ke folder plugins/ di setiap server dan proxy yang ingin dilindungi.
  2. Restart server.
  3. Cek console. Hasil pemindaian akan muncul saat server menyala.

Kalau ada plugin terdeteksi

  1. Hapus file jar plugin tersebut dari folder plugins/.
  2. Download ulang plugin dari sumber resmi (SpigotMC, Hangar, Modrinth, atau GitHub pembuatnya).
  3. Ganti password panel dan database kalau plugin berbahaya sempat aktif.
  4. Cek backup lama. Backup yang dibuat saat plugin berbahaya terpasang juga bisa ikut terinfeksi.
Pencegahan: malware Minecraft paling sering menyebar lewat plugin premium bajakan. Jangan memasang plugin dari situs atau grup yang tidak jelas.
