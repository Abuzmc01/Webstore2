Membuat Server Minecraft

Langkah awal menyiapkan server Minecraft baru di MineIDHost, dari memilih software sampai pemain pertama join.

1. Pilih software server

SoftwareCocok untuk
PaperServer plugin pada umumnya. Ringan dan paling banyak didukung plugin.
PurpurSama seperti Paper, dengan lebih banyak opsi pengaturan gameplay.
VelocityProxy untuk menggabungkan beberapa server. Lihat Setup Velocity.
Fabric / Forge / NeoForgeServer modpack. Tidak bisa memakai plugin.
VanillaMinecraft asli tanpa plugin dan mod.

2. Pilih versi Minecraft

Pilih versi yang didukung plugin atau modpack kamu. Pastikan versi Java juga sesuai, lihat Versi Java Server.

3. Start server

Buka Console dan klik Start. Server siap kalau muncul tulisan Done.

4. Join server

Alamat server ada di bagian atas Console (format alamat:port). Di Minecraft Java: Multiplayer → Add Server, lalu tempel alamat tersebut.

Langkah berikutnya: beri diri kamu OP (Menjadi Operator), pasang plugin (Install Plugin), dan atur optimasi.
